# evaluatesystem — ระบบประเมินผลการปฏิบัติงาน โรงเรียนบ้านป่าเด็ง

ระบบประเมิน PA และครูผู้ช่วยที่แยก repo, Worker และการ deploy ออกจากระบบโรงเรียน

- Repo: SATTASAI/evaluatesystem
- Cloudflare Worker: evaluatesystem
- เว็บไซต์: https://evaluate.banpadengschool.ac.th/
- ระบบโรงเรียน: https://system.banpadengschool.ac.th/

## การเชื่อมข้อมูล

ใช้ Cloudflare D1 `banpadeng_school_db` ชุดเดียวกันเพื่อเชื่อมรหัสบัญชี บุคลากร หัวหน้าฝ่าย และผลที่ยืนยันแล้ว โดยตารางประเมินเป็นของแอปนี้ ไม่มีการคัดลอกทะเบียนหรือแก้ชื่อบุคลากรจากระบบประเมิน

ระบบนี้ไม่เก็บหรือรับรหัสผ่านโรงเรียน และไม่ใช้ JWT_SECRET ของโรงเรียน การเข้าสู่ระบบส่งผู้ใช้ไปยืนยันบัญชีบนระบบโรงเรียน แล้วคืนรหัสใช้ครั้งเดียวอายุ 120 วินาที ต้องตรงกับ state/cookie ที่เริ่มจากเบราว์เซอร์เดียวกัน จึงออก session ของระบบประเมินให้ 7 วัน

ทุกคำขออ่าน role/status/session_version และหัวหน้าฝ่ายจากฐานปัจจุบัน การระงับบัญชี การออกจากทุกอุปกรณ์ หรือการเปลี่ยนสิทธิ์จึงมีผลทันที คะแนนร่างและผลที่ยังไม่ยืนยันไม่ปรากฏในฝ่ายบุคลากร

ผู้ทรงคุณวุฒิภายนอกใช้ลิงก์เชิญเฉพาะรายตามระบบเดิม สิทธิ์สูงสุด 7 วัน ไม่มีบัญชีโรงเรียน และไม่เห็นผลกรรมการคนอื่น

## Deploy

Cloudflare เชื่อม repo นี้ branch main โดยใช้ root `/` และคำสั่ง `npx wrangler deploy` ไฟล์ `wrangler.jsonc` ระบุชื่อ Worker และเฉพาะ assets/API ของระบบประเมิน

D1 binding `DB` ใช้ database_id เดิมตาม config เพื่อให้หน้าผลในฝ่ายบุคลากรอ่านได้ทันที ไม่ต้องสร้างฐานใหม่หรือคัดลอก secrets ของระบบโรงเรียน

กำหนด `evaluate.banpadengschool.ac.th` เป็น Custom Domain ของ Worker `evaluatesystem` ตัวนี้ ไม่ใช่ Route ที่ไม่มี DNS

## การตั้งเกณฑ์

เกณฑ์แต่ละรุ่นแยกจากกันและถูก snapshot ไว้ในรอบ คะแนนที่ส่งแล้วล็อกจนผู้จัดรอบเปิดแก้พร้อมเหตุผล ผลเผยแพร่ได้โดยผู้บริหารหลังกรรมการส่งครบ

แบบ PA และครูผู้ช่วยยังต้องเทียบกับแบบ ก.ค.ศ. ฉบับที่โรงเรียนใช้ก่อนเปิดรอบจริง โดยเฉพาะรายการย่อย ว19/2568 แบบเริ่มต้นที่มี “รอระบุรายการ” ใช้ประเมินจริงไม่ได้
