การเชื่อมต่อ LINE Official Account

รับ Group ID ผ่าน Webhook เลือกกลุ่มปลายทาง และทดสอบการแจ้งเตือนจากหน้าเดียว

กำลังตรวจสอบการเชื่อมต่อ...

ระบบกำลังตรวจ Secret, Access Token และกลุ่มปลายทาง

Channel secretกำลังตรวจสอบ
Channel access tokenกำลังตรวจสอบ
กลุ่มปลายทางที่เลือกกำลังตรวจสอบ
✓

รับเฉพาะข้อมูลที่จำเป็น

Webhook ตรวจลายเซ็นจาก LINE ก่อนทุกครั้ง ระบบเก็บเฉพาะรหัสปลายทาง ประเภทเหตุการณ์ และเวลาที่ได้รับ ไม่เก็บข้อความสนทนาในกลุ่ม

Webhook URL

นำ URL นี้ไปวางใน LINE Developers → Messaging API → Webhook settings

กลุ่มที่ระบบตรวจพบ

เพิ่ม LINE Official Account เข้ากลุ่ม แล้วให้สมาชิกคนใดก็ได้ส่งข้อความหนึ่งครั้ง จากนั้นกด “ตรวจสอบอีกครั้ง”

กำลังโหลดข้อมูล...
หากเพิ่งเปิด Webhook ให้กด Verify และเปิด Use webhook ก่อน จากนั้นตรวจว่าเปิด Allow bot to join group chats แล้วจึงเชิญบัญชีทางการเข้ากลุ่ม

ขั้นตอนเชื่อมต่อ

ทำตามลำดับเพื่อให้ระบบพบกลุ่มอัตโนมัติ

1
คัดลอก Webhook URLวางในหน้า Messaging API ของ LINE Developers
2
กด Verifyเมื่อขึ้น Success ให้เปิดสวิตช์ Use webhook
3
เชิญ OA เข้ากลุ่มสมาชิกในกลุ่มส่งข้อความหนึ่งครั้ง
4
เลือกกลุ่มปลายทางกดปุ่ม “ใช้กลุ่มนี้” แล้วส่งข้อความทดสอบ

ข้อควรทราบ

LINE อาจใช้เวลาสองสามวินาทีในการส่งเหตุการณ์ หลังส่งข้อความในกลุ่มแล้วให้รอสักครู่ก่อนรีเฟรช
