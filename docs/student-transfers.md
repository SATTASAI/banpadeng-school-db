# ทะเบียนคำร้องย้ายเข้า–ย้ายออก

Frontend source อยู่ใน `SATTASAI/dmcreport`; production build ถูกเก็บที่ `public/dmcreport/` และให้บริการผ่าน `/dmcreport/` ใช้บัญชี/session โรงเรียนเดิม เพื่อไม่ต้องแชร์รหัสผ่านหรือขยาย cookie ไปยัง subdomain ใหม่

API อยู่ที่ `src/routes/student-transfers.js` สร้างตารางเพิ่มใน binding DB เดิมเมื่อใช้งาน โดยไม่ลบหรือแก้ข้อมูลเดิม ไฟล์ใช้ Google Drive service เดิมและมีการตรวจชนิด/ขนาดไฟล์ก่อนอัปโหลด การเปิดไฟล์ตรวจสิทธิ์เจ้าหน้าที่/ผู้บริหารทุกครั้ง

Dashboard เพิ่มยอดคำร้องทุกปีการศึกษาและยอดอนุมัติย้ายเข้า/ออกจากตารางคำร้อง ใช้ revision triggers และ polling เดิม ไม่มีรายชื่อนักเรียนแสดงในสรุปสาธารณะ/บัญชีผู้ชม ครูทั่วไปและผู้ชมเข้า API คำร้องไม่ได้

การอนุมัติเป็นผลพิจารณาคำร้องเท่านั้น การปรับทะเบียนนักเรียนหลัก สถานะรายภาค และผลการเรียนยังดำเนินการในระบบรายงานผลการเรียนซึ่งเป็นเจ้าของข้อมูลตาม `grade-owned.js` ไม่มีการเปลี่ยน roster ซ้ำจากคำร้องนี้

สิทธิ์: staff/executive/superadmin บันทึกและตรวจเอกสาร; executive/superadmin อนุมัติหรือไม่อนุมัติ ต้องตรวจไฟล์ทั้ง 3 รายการครบก่อนอนุมัติ เปลี่ยนไฟล์แล้วผลตรวจเอกสารนั้นถูกรีเซ็ต สถานะสิ้นสุดล็อกการแก้ไข ประวัติการพิจารณาเก็บแยกและการแก้ไขใช้ version guard ภายใน batch เดียวกัน

ทดสอบ: `node --test tests/student-transfers.test.mjs tests/dashboard-live.test.mjs` และชุดทดสอบเดิมทั้งหมด Fixture ใช้ SQLite ในหน่วยความจำและ fake storage ไม่มีข้อมูลนักเรียนจริงหรือไฟล์ส่วนบุคคล
