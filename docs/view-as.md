# โหมดมุมมองบุคคลอื่น (ทดสอบการมองเห็น)

ผู้ดูแลระบบ (superadmin) เปิดระบบในสิทธิ์ของบัญชีอื่นได้ เพื่อทดสอบว่าบัญชีนั้นเห็นเมนูและข้อมูลอะไรบ้าง

- เริ่มที่ **ผู้ใช้และสิทธิ์ → ปุ่ม "ดูในมุมมองนี้"** ในแถวของบัญชีที่ต้องการ
- ระหว่างนี้มีแถบสีส้มเข้มด้านบน ใช้สลับไปดูบัญชีอื่น หรือกด **"กลับเป็นบัญชีของฉัน"**
- **ดูได้อย่างเดียว**: การบันทึก แก้ไข ส่งเอกสาร หรือส่งแจ้งเตือน LINE ในนามบัญชีนั้นถูกบล็อก (HTTP 403 `VIEW_AS_READ_ONLY`)
- มีผลเฉพาะอุปกรณ์/เบราว์เซอร์ที่กดเริ่ม (ผูกกับ session) อุปกรณ์อื่นของผู้ดูแลยังเป็นบัญชีผู้ดูแลตามปกติ
- สิ้นสุดอัตโนมัติใน 60 นาที, เมื่อออกจากระบบ, หรือเมื่อบัญชีผู้ดูแลถูกลดสิทธิ์
- บันทึกการเริ่ม/จบไว้ใน audit_logs (`view_as_start`, `view_as_end`)
- ระบบรายงานผลการเรียน (grades) ไม่ได้รับผลจากโหมดนี้

โค้ด: `src/lib/view-as.js`, `src/routes/view-as.js`, `src/lib/auth.js` (loadCurrentUser), `public/js/view-as.js`
