# ระบบลงทะเบียนนิเทศ (นิเทศพร้อม)

ครูลงทะเบียนขอรับการนิเทศการสอนหรือนิเทศห้องเรียน → ผู้มีสิทธิ์ประเมินรับนิเทศ → ผู้รับนิเทศบันทึกคะแนน → ครูเห็นผลและข้อเสนอแนะ

## เมนู
- ระบบสนับสนุน → **ลงทะเบียนนิเทศ** (`/supervision.html`) — ทุกคน: ลงทะเบียน นัดหมายของฉัน ผลของฉัน
- ฝ่ายบริหาร → **นิเทศการสอน** (`/supervision-admin.html`) — แสดงเฉพาะผู้มีสิทธิ์ประเมิน: คำขอ รับนิเทศ บันทึกคะแนน ผล
- ฝ่ายบุคคล → **ผลการนิเทศ** (`?view=results`) และ **ผู้มีสิทธิ์ประเมินนิเทศ** (`?view=evaluators`)

## สิทธิ์ (`GET /api/supervision/permissions`)
| สิทธิ์ | ใคร |
|---|---|
| ลงทะเบียน/ดูผลของตนเอง | ผู้ใช้ทุกคน — เห็นเฉพาะคำขอและผลของตนเอง |
| ประเมิน (`evaluate`) | ผู้อำนวยการ รองผู้อำนวยการ (role `executive` หรือตำแหน่งในทะเบียนบุคลากร ไม่รวมผู้ช่วยผู้อำนวยการ) และผู้ที่ได้รับแต่งตั้งใน `supervision_evaluators` |
| เห็นผลทุกคน (`view_all`) | ฝ่ายบริหาร ฝ่ายบุคคล (ทำเนียบฝ่ายหรือสังกัดในทะเบียน) และผู้ดูแลระบบ |
| แต่งตั้งผู้ประเมิน (`manage_evaluators`) | หัวหน้าฝ่ายบุคคล และ superadmin |

ผู้ได้รับแต่งตั้งที่ไม่ใช่ฝ่ายบริหาร/ฝ่ายบุคคล เห็นรายการคำขอทั้งหมดเพื่อรับนิเทศ แต่เห็นคะแนนเฉพาะรายการที่ตนประเมิน ไม่มีใครรับนิเทศคำขอของตนเอง

## กติกา
- เลือกได้เฉพาะวันจันทร์–ศุกร์ในภาคเรียน และคาบที่ยังไม่เริ่ม (เวลาไทย ตามโครงเวลาเรียนของภาค)
- ภาคที่มี **ตารางสอนเผยแพร่แล้ว**: เลือกได้เฉพาะคาบที่ครูสอน วิชา/ห้องดึงจากตาราง (`source='timetable'`)
- ภาคที่ **ยังไม่มีตารางสอนเผยแพร่**: ครูกรอกวิชาและชั้นเอง (`source='manual'`)
- ครูจองคาบเดียวกันซ้ำไม่ได้ ผู้นิเทศรับนิเทศวันและคาบเดียวกันได้รายการเดียว (unique index ในฐานข้อมูล)
- ยกเลิกได้เฉพาะเจ้าของคำขอ ก่อนประเมิน; ผู้รับนิเทศถอนการรับได้ก่อนประเมิน
- บันทึกคะแนนได้เฉพาะผู้รับนิเทศ ต้องครบ 5 ข้อ ข้อละ 1–5 · ร้อยละ = รวม ÷ 25 × 100 · บันทึกแล้วแก้ทับไม่ได้
- ระดับ: ≥90 ดีเยี่ยม · ≥80 ดีมาก · ≥70 ดี · ≥60 พอใช้ · <60 ควรพัฒนา
- เก็บชื่อข้อประเมินพร้อมคะแนน (`items_json`) เพื่อให้ผลเดิมถูกต้องแม้แก้แบบประเมินภายหลัง

## แจ้งเตือน
`supervision_notifications` รวมเข้ากระดิ่ง (`/api/notifications`, ข้อความ `supervision:<id>`) และส่ง LINE รายบุคคลผ่าน line-feed เดิม
- คำขอใหม่ → ผู้มีสิทธิ์ประเมินทุกคน · รับนิเทศ/ถอนการรับ → ครู และผู้ประเมินอื่น · บันทึกผล → ครู · ยกเลิก → ผู้รับนิเทศ (หรือผู้ประเมินทุกคนถ้ายังไม่มีผู้รับ)

## ตาราง
`supervision_requests`, `supervision_evaluations`, `supervision_evaluators`, `supervision_notifications` — สร้างเองเมื่อเรียก API ครั้งแรก (`ensureSupervisionSchema`)
