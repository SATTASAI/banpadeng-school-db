# งานวิเคราะห์ผู้เรียนรายบุคคล

ทางเข้า: แดชบอร์ด → ข้อมูลนักเรียน → งานวิเคราะห์ผู้เรียนรายบุคคล หรือปุ่มบนหน้าทะเบียนนักเรียน

1. เลือกปีการศึกษา ภาคเรียน ระดับชั้น และห้องเรียน ระบบแสดงเฉพาะระดับชั้นและห้องที่มีนักเรียนกำลังศึกษาอยู่ตามทะเบียน `student_enrollments` ของภาคเรียนนั้น จึงไม่ดึงรายชื่อนักเรียนจากห้องปัจจุบันไปใส่ปีเก่า และแยกห้องชื่อซ้ำกันคนละระดับชั้น
2. เลือกนักเรียน ตรวจข้อมูลทะเบียนที่แสดงในแบบแก้ไข กรอกผลและหลักฐานของการอ่าน การเขียน การคิด/สื่อสาร และพฤติกรรมการเรียน รวมถึงจุดเด่น สิ่งที่ควรพัฒนา เป้าหมาย กิจกรรม/วิธีช่วยเหลือ ผู้รับผิดชอบ ระยะเวลาดำเนินการ และผลติดตาม กด **บันทึกผลวิเคราะห์**
   แบบฉบับใหม่มีข้อมูลจากนักเรียน (ความสนใจ วิธีเรียนรู้ที่ชอบ ความคาดหวัง สิ่งที่อยากบอกครู) บริบทครอบครัวที่เกี่ยวข้องกับการเรียน และผลประเมินพร้อมหลักฐาน 5 ด้าน ได้แก่ ความรู้/ประสบการณ์ การคิด/เรียนรู้ พฤติกรรม ร่างกาย/สุขภาวะ และสังคม ครูเลือกกลุ่มเพื่อวางแผนจัดการเรียนรู้ได้โดยอาศัยผลที่ประเมินจริง ระบบไม่จัดกลุ่มอัตโนมัติจากข้อมูลสุขภาพหรือครอบครัว
3. กด **พิมพ์รายคน** หรือ **พิมพ์ทั้งห้อง** รายห้องจะเรียงนักเรียนที่กำลังศึกษาอยู่ในภาคเรียน ระดับชั้น และห้องนั้น คนที่ยังไม่บันทึกจะพิมพ์เป็นแบบฟอร์มว่างพร้อมข้อมูลทะเบียนที่มีจริง

ผู้บริหารหรือผู้ดูแลระบบเปิดหน้าเดียวกัน เลือกปี ภาคเรียน ระดับชั้น และห้อง แล้วใช้ส่วน **มอบหมายครูผู้จัดทำงานวิเคราะห์** ระบุครูหรือบุคลากรได้หลายคนต่อห้อง การมอบหมายแยกตามภาคเรียน ครูจะเห็นเฉพาะห้องที่ได้รับมอบหมาย และเมื่อถอนสิทธิ์จะอ่าน บันทึก หรือพิมพ์ข้อมูลของห้องนั้นไม่ได้ทันที ผู้บริหารและผู้ดูแลยังดูได้ทุกห้อง ข้อมูลครูประจำชั้นจากทะเบียนบุคลากรเป็นข้อความอิสระ จึงไม่ใช้เป็นสิทธิ์อัตโนมัติ

ผลวิเคราะห์บันทึกใน Cloudflare D1 ตาราง `learner_analyses` แยกตามนักเรียน ภาคเรียน และบัญชีครูผู้จัดทำ หากมีช่องที่ไม่มีข้อมูล เอกสารจะเว้นว่าง และไม่ดึงผลการเรียนหรือข้อมูลมาเรียนจาก Q-Info อัตโนมัติ

แหล่งอ้างอิงของแบบฉบับใหม่: เอกสาร Word “วิเคราะห์ผู้เรียนรายบุคคล” ที่ผู้ใช้ส่งให้ (ส่วนแนวทางวิเคราะห์ 5 ด้าน และแบบรายบุคคลในภาคผนวก) นำเฉพาะโครงสร้างคำถามมาใช้ ไม่คัดลอกข้อมูลเด็ก รายชื่อ หรือความเห็นเฉพาะบุคคลจากต้นฉบับขึ้นระบบ และใช้ชื่อกลุ่มที่เป็นกลางแทนคำจัดประเภทด้านสติปัญญาจากต้นฉบับ

ความพร้อมของข้อมูล: รายชื่อ ชั้น และห้องมาจากทะเบียนนักเรียนตามภาคเรียน มีทางดาวน์โหลดแม่แบบนำเข้าทะเบียนนักเรียนในหน้าวิเคราะห์ และจัดการปีการศึกษาได้จากลิงก์บนหน้าเดียวกัน ข้อมูลคำตอบและการประเมินรายคนกรอกในแบบฟอร์มโดยตรง ไม่ต้องนำเข้าจากไฟล์ Excel

การพิมพ์ใช้กระดาษ A4 แนวตั้ง แยกข้อมูลทะเบียน/เสียงนักเรียน/ความพร้อม 5 ด้านในหน้าแรก และทักษะ/สรุป/แผนช่วยเหลือ/ติดตามผลในหน้าที่สองของแต่ละคน เนื้อหาปกติจัดวางสองหน้า ข้อความที่ครูกรอกยาวมากจะไหลต่อหน้าใหม่เพื่อไม่ตัดข้อมูล ฟอนต์ TH SarabunPSK ขนาด 16 pt ทั้งฉบับจาก `public/fonts/THSarabunPSK-Regular.ttf` และ `public/fonts/THSarabunPSK-Bold.ttf` ซึ่งโหลดจากเว็บไซต์ของระบบทั้งสองน้ำหนักก่อนเปิดหน้าพิมพ์ จึงไม่ต้องติดตั้งฟอนต์ในเครื่อง ตราโรงเรียนมาจาก `public/logo.jpg` ถ้าฟอนต์โหลดไม่สำเร็จ ระบบจะแจ้งให้ลองใหม่แทนการพิมพ์ด้วยฟอนต์อื่น

แหล่งไฟล์ฟอนต์: [SarabunConsortium/TH-Sarabun-PSK](https://github.com/SarabunConsortium/TH-Sarabun-PSK) ผู้สร้างต้นแบบ: ศุภกิจ เฉลิมลาภ (ตาม [หน้าฟอนต์ของ SIPA](https://www.f0nt.com/release/13-free-fonts-from-sipa/)) เงื่อนไขที่แจกพร้อมไฟล์ฟอนต์เก็บไว้ใน `public/fonts/OFL.txt`

ข้อมูลสุขภาพและผู้ปกครองจะอ่านเมื่อเปิดรายคนหรือเตรียมเอกสารพิมพ์ ไม่ส่งรวมมากับรายชื่อใน sidebar; หน้ารายชื่อและ API ต้องผ่านการเข้าสู่ระบบ และผลวิเคราะห์ที่บันทึกไว้จะถูกเรียกตามบัญชีครูผู้จัดทำ
