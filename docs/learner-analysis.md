# งานวิเคราะห์ผู้เรียนรายบุคคล

ทางเข้า: แดชบอร์ด → ข้อมูลนักเรียน → งานวิเคราะห์ผู้เรียนรายบุคคล หรือปุ่มบนหน้าทะเบียนนักเรียน

1. เลือกปีการศึกษา ภาคเรียน และห้องเรียน ระบบใช้ทะเบียน `student_enrollments` ของภาคเรียนนั้น จึงไม่ดึงรายชื่อนักเรียนจากห้องปัจจุบันไปใส่ปีเก่า
2. เลือกนักเรียน กรอกผลและหลักฐานของการอ่าน การเขียน การคิด/สื่อสาร และพฤติกรรมการเรียน รวมถึงจุดเด่น สิ่งที่ควรพัฒนา แผนช่วยเหลือ และผลติดตาม กด **บันทึกผลวิเคราะห์**
3. กด **พิมพ์รายคน** หรือ **พิมพ์ทั้งห้อง** รายห้องจะเรียงนักเรียนที่กำลังศึกษาอยู่ในภาคเรียนและห้องนั้น คนที่ยังไม่บันทึกจะพิมพ์เป็นแบบฟอร์มว่างพร้อมข้อมูลทะเบียนที่มีจริง

ผลวิเคราะห์บันทึกใน Cloudflare D1 ตาราง `learner_analyses` แยกตามนักเรียน ภาคเรียน และบัญชีครูผู้จัดทำ หากมีช่องที่ไม่มีข้อมูล เอกสารแสดง `–` และไม่ดึงผลการเรียนหรือข้อมูลมาเรียนจาก Q-Info อัตโนมัติ

การพิมพ์ใช้กระดาษ A4 แนวตั้ง และกำหนด `font-family: "TH SarabunPSK"` ขนาด 16 pt ใน CSS หน้า print ตราโรงเรียนมาจาก `public/logo.jpg` หากเครื่องผู้พิมพ์ไม่มี TH SarabunPSK เบราว์เซอร์จะเลือกฟอนต์สำรอง เพื่อรับประกันฟอนต์ตรงกันทุกเครื่องต้องเพิ่มไฟล์ฟอนต์ที่ใช้งานได้ตามสิทธิ์ใน `public/fonts/` และประกาศ `@font-face` ใน CSS ก่อนใช้งานทั่วโรงเรียน

ข้อมูลสุขภาพและผู้ปกครองจะอ่านเมื่อเตรียมเอกสารพิมพ์ ไม่ส่งรวมมากับรายชื่อใน sidebar; หน้ารายชื่อและ API ต้องผ่านการเข้าสู่ระบบ และผลวิเคราะห์ที่บันทึกไว้จะถูกเรียกตามบัญชีครูผู้จัดทำ
