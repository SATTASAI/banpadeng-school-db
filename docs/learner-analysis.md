# งานวิเคราะห์ผู้เรียนรายบุคคล

ทางเข้า: แดชบอร์ด → ข้อมูลนักเรียน → งานวิเคราะห์ผู้เรียนรายบุคคล หรือปุ่มบนหน้าทะเบียนนักเรียน

1. เลือกปีการศึกษา ภาคเรียน ระดับชั้น และห้องเรียน ระบบแสดงเฉพาะระดับชั้นและห้องที่มีนักเรียนกำลังศึกษาอยู่ตามทะเบียน `student_enrollments` ของภาคเรียนนั้น จึงไม่ดึงรายชื่อนักเรียนจากห้องปัจจุบันไปใส่ปีเก่า และแยกห้องชื่อซ้ำกันคนละระดับชั้น
2. เลือกนักเรียน กรอกผลและหลักฐานของการอ่าน การเขียน การคิด/สื่อสาร และพฤติกรรมการเรียน รวมถึงจุดเด่น สิ่งที่ควรพัฒนา แผนช่วยเหลือ และผลติดตาม กด **บันทึกผลวิเคราะห์**
3. กด **พิมพ์รายคน** หรือ **พิมพ์ทั้งห้อง** รายห้องจะเรียงนักเรียนที่กำลังศึกษาอยู่ในภาคเรียน ระดับชั้น และห้องนั้น คนที่ยังไม่บันทึกจะพิมพ์เป็นแบบฟอร์มว่างพร้อมข้อมูลทะเบียนที่มีจริง

ผลวิเคราะห์บันทึกใน Cloudflare D1 ตาราง `learner_analyses` แยกตามนักเรียน ภาคเรียน และบัญชีครูผู้จัดทำ หากมีช่องที่ไม่มีข้อมูล เอกสารแสดง `–` และไม่ดึงผลการเรียนหรือข้อมูลมาเรียนจาก Q-Info อัตโนมัติ

การพิมพ์ใช้กระดาษ A4 แนวตั้ง ฟอนต์ TH SarabunPSK ขนาด 16 pt จาก `public/fonts/THSarabunPSK-Regular.ttf` และ `public/fonts/THSarabunPSK-Bold.ttf` ซึ่งโหลดจากเว็บไซต์ของระบบทั้งสองน้ำหนักก่อนเปิดหน้าพิมพ์ จึงไม่ต้องติดตั้งฟอนต์ในเครื่อง ตราโรงเรียนมาจาก `public/logo.jpg` ถ้าฟอนต์โหลดไม่สำเร็จ ระบบจะแจ้งให้ลองใหม่แทนการพิมพ์ด้วยฟอนต์อื่น

แหล่งไฟล์ฟอนต์: [SarabunConsortium/TH-Sarabun-PSK](https://github.com/SarabunConsortium/TH-Sarabun-PSK) ผู้สร้างต้นแบบ: ศุภกิจ เฉลิมลาภ (ตาม [หน้าฟอนต์ของ SIPA](https://www.f0nt.com/release/13-free-fonts-from-sipa/)) เงื่อนไขที่แจกพร้อมไฟล์ฟอนต์เก็บไว้ใน `public/fonts/OFL.txt`

ข้อมูลสุขภาพและผู้ปกครองจะอ่านเมื่อเตรียมเอกสารพิมพ์ ไม่ส่งรวมมากับรายชื่อใน sidebar; หน้ารายชื่อและ API ต้องผ่านการเข้าสู่ระบบ และผลวิเคราะห์ที่บันทึกไว้จะถูกเรียกตามบัญชีครูผู้จัดทำ
