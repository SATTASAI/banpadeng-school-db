# Dashboard ตัวเลขสด

- โหลดข้อมูลใหม่ทันทีหลัง API บันทึกสำเร็จ ผ่าน event ในหน้าปัจจุบัน,
  postMessage จาก iframe และ BroadcastChannel ระหว่างแท็บต้นทางเดียวกัน
- รีเฟรชทันทีเมื่อกลับมาหน้าภาพรวม เปลี่ยนปีงบประมาณ หรือกลับมาเปิดแท็บ
- ตรวจ `/api/overview/revision` ทุก 2 วินาทีเมื่อมองเห็นหน้าภาพรวม
  โหลดข้อมูลสรุปทั้งหมดเฉพาะเมื่อ revision เปลี่ยน ไม่ยิงรายการสรุปหนักทุก 2 วินาที
- Database triggers เพิ่ม revision หลังเพิ่ม แก้ไข หรือลบข้อมูลในโครงการ,
  รายรับ เบิกจ่าย การลา นักเรียน บุคลากร งาน ปีการศึกษา และพัสดุ
  การติดตั้ง trigger เกิดใน runtime จึงรองรับ D1 เดิมโดยไม่ลบข้อมูล
- การอ่าน dashboard ใช้ D1 Session แบบ first-primary และ Cache-Control no-store
  เพื่อเริ่มอ่านข้อมูลล่าสุดจาก primary หาก runtime รองรับ session
- แสดงทุกปีงบประมาณเป็นค่าเริ่มต้น มีตัวเลือกแยกปี ไม่ซ่อนโครงการปีเดิม
- เงินจัดสรรโครงการและวงเงินคงเหลือแยกจากรายรับจริง/เบิกจ่ายจริง
  ยอดใช้โครงการอ่านจากรายการ paid โดยตรง ไม่พึ่งยอดสะสมที่อาจเก่า
- สถิติการลาแสดง pending/approved/rejected แยกประเภท
  วันลานับตามปฏิทินและเฉพาะคำขอที่อนุมัติ เมื่อเลือกปีนับเฉพาะวันที่อยู่ในปีนั้น
  ผู้ลาวันนี้นับจำนวนคนไม่ซ้ำตามวันในประเทศไทย

การตรวจ revision เป็นการ polling ไม่ใช่ WebSocket push จึงมีเวลาแสดงผล
สำหรับการเปลี่ยนโดยเครื่องอื่นประมาณ 2 วินาที บวกเวลาเครือข่ายและโหลดข้อมูล
ไม่รวมเวลาที่แท็บถูกพักโดยเบราว์เซอร์
