# สถิติการมาเรียนบนแดชบอร์ด (ซิงค์กับระบบรายงานผลการเรียน)

แดชบอร์ดอ่านข้อมูลการมาเรียนจากระบบรายงานผลการเรียน (grades.banpadengschool.ac.th / repo students-report) ซึ่งใช้ฐานข้อมูล D1 เดียวกัน
ระบบนี้**อ่านอย่างเดียว** ครูประจำชั้นบันทึกที่ grades → `/homeroom.html` แท็บ "บันทึกการมาเรียน" (ตาราง `gr_attendance`)

## กติกา (เหมือน grades: `src/lib/data.js` → `schoolCalendar`, `attendanceRates`)
- วันเรียน = จันทร์–ศุกร์ ในช่วงภาคเรียน (`academic_terms`) ที่ไม่ใช่วันหยุดใน `gr_holidays`
- grades เก็บเฉพาะนักเรียนที่ไม่ได้มาปกติ: ข ขาดเรียน · ล ลากิจ · ป ลาป่วย · ส มาสาย — ไม่มีบันทึก = มาเรียน, มาสายนับว่ามาเรียน
- ร้อยละมาเรียนทั้งปี = (วันเรียนถึงวันนี้ − ข/ล/ป) ÷ วันเรียน · นักเรียนย้ายเข้านับจากวันที่ย้ายเข้า (`gr_transfers`)
- เกณฑ์ใช้ `gr_settings.attendance_pass_pct` (ค่าเริ่มต้น 80%)
- รายชื่อ = การลงทะเบียนภาคเรียนล่าสุดของปีการศึกษาที่เปิดใช้ สถานะ enrolled (ไม่รวมย้ายออก/ออกกลางคัน)
- วันที่ไม่มีเรียน (ปิดภาค/วันหยุด) แสดงวันเรียนล่าสุด
- ถ้ายังไม่มีบันทึกเลย แสดงข้อความ "ครูประจำชั้นยังไม่ได้บันทึก" แทนตัวเลข 100% ที่ทำให้เข้าใจผิด

## โค้ด
- `src/lib/student-attendance.js` → `attendanceDashboard(env)` ส่งออกใน `/api/overview` เป็น `attendance_summary`
- แดชบอร์ดอัปเดตทันทีเมื่อครูบันทึกใน grades: trigger ของ `dashboard_revision` ครอบคลุม `gr_attendance`, `gr_holidays`, `student_enrollments`
- ทดสอบ: `tests/student-attendance.test.mjs`

## หน้าแดชบอร์ด
แบ่งเป็นแท็บ (จำแท็บล่าสุดไว้ในเบราว์เซอร์): ภาพรวม · นักเรียน·มาเรียน · บุคลากร · งบประมาณ
แผนภูมิสัดส่วนงบแสดงทีละฝ่าย (ปุ่มเลือกฝ่าย) รายการโครงการของแต่ละฝ่ายพับไว้ ใบประกอบวิชาชีพแสดงเฉพาะที่ต้องติดตามก่อน
