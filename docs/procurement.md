# งานจัดซื้อจัดจ้าง (ฝ่ายงบประมาณ)

หน้า `/procurement.html` (เมนู ฝ่ายงบประมาณ › จัดซื้อจัดจ้าง) · API `src/routes/procurement.js`

## ขั้นตอน

1. ครูส่งคำขอเบิกจ่ายโครงการตามเดิม → เจ้าหน้าที่การเงินรับเรื่อง
2. **เจ้าหน้าที่พัสดุ** เลือกคำขอที่รอดำเนินการ (`finance_queue` / `finance_processing`) แล้วจัดทำรายงานขอซื้อ/ขอจ้าง
   ระบบดึงรายการจากคำขอมาให้ แก้ไขได้ ยอดรวมต้องไม่เกินยอดคำขอ และเลือกผู้ตรวจรับพัสดุ
3. ส่งรายงาน → **หัวหน้าเจ้าหน้าที่พัสดุ** เห็นชอบ (ข้ามขั้นนี้ถ้าไม่ได้กำหนด หรือเป็นคนเดียวกับผู้จัดทำ)
4. **ผู้อำนวยการ** อนุมัติรายงาน และแต่งตั้งผู้ตรวจรับ (อนุมัติรายงานที่ตนเองจัดทำไม่ได้) หรือส่งกลับพร้อมเหตุผล
5. เจ้าหน้าที่ออกใบสั่งซื้อ/สั่งจ้าง (เลขที่ `PO-ปีงบ-ลำดับ` / `WO-ปีงบ-ลำดับ` หรือกรอกเอง) กำหนดส่งมอบคำนวณจากจำนวนวัน
6. ผู้ขายส่งของ → เจ้าหน้าที่บันทึกวันที่ส่งมอบและเลขใบส่งของ → ระบบแจ้งผู้ตรวจรับ
7. ผู้ตรวจรับแต่ละคนกด **ตรวจรับ** ในระบบ ครบทุกคนแล้วจึงถือว่าตรวจรับ
   ถ้ามีคนกด **ไม่รับพัสดุ** ผลตรวจทุกคนถูกล้าง และต้องบันทึกการส่งมอบใหม่
8. ตรวจรับครบ → นำเข้าทะเบียนพัสดุอัตโนมัติ และแจ้งการเงิน/เจ้าของโครงการ
9. การเงินกด "ตรวจแล้ว เสนอผู้อำนวยการ" เพื่ออนุมัติเบิกจ่ายตามเดิม
   **ระบบไม่ให้กดขั้นนี้ ถ้าคำขอมีงานจัดซื้อจัดจ้างที่ยังไม่ตรวจรับ** (ยกเลิกงานจัดซื้อได้ถ้าไม่ต้องใช้)

## กติกาที่ระบบตรวจ

- หนึ่งคำขอเบิก มีงานจัดซื้อที่ยังไม่ยกเลิกได้ 1 งาน
- วงเงินเกิน 100,000 บาท ต้องมีคณะกรรมการตรวจรับอย่างน้อย 3 คน (คนแรกเป็นประธาน) ไม่เกินนั้นใช้ผู้ตรวจรับ 1 คนได้
- เลือก 3 คนขึ้นไป เอกสารจะเรียกเป็น "คณะกรรมการตรวจรับพัสดุ"
- วิธีเฉพาะเจาะจงเป็นค่าเริ่มต้น พร้อมเหตุผลตามมาตรา 56 วรรคหนึ่ง (2) (ข) แก้ข้อความได้
- ถ้าคำขอเบิกถูกส่งกลับ/ไม่อนุมัติระหว่างทาง จะส่งรายงานหรืออนุมัติต่อไม่ได้จนกว่าคำขอกลับมาที่ฝ่ายงบประมาณ

## การเข้าทะเบียนพัสดุ

| ประเภทรายการ | ผลในทะเบียนพัสดุ |
|---|---|
| วัสดุ | ถ้ามีรายการเดิมที่ชื่อและหน่วยตรงกัน (สถานะใช้งาน) เพิ่มยอดรับเข้า ไม่เช่นนั้นสร้างทะเบียนใหม่ `MAT-ปีงบ-ลำดับ` |
| ครุภัณฑ์ | สร้างทะเบียนแยกทีละหน่วย `EQP-ปีงบ-ลำดับ` (จำนวนเต็มไม่เกิน 100) |
| งานจ้าง/บริการ | ไม่เข้าทะเบียน |

ทุกรายการบันทึกเป็นการเคลื่อนไหว "รับเข้า" อ้างเลขใบสั่ง ผู้ขาย แหล่งเงินของโครงการ วันที่ส่งมอบ และฝ่ายของโครงการ
แก้รหัสครุภัณฑ์ สถานที่ หรือผู้รับผิดชอบภายหลังได้ที่หน้าพัสดุและครุภัณฑ์ การนำเข้ากันซ้ำด้วยตาราง `procurement_postings`

## เอกสารที่พิมพ์ได้

`/api/procurement/cases/:id/documents/...`

- `report` รายงานขอซื้อ/ขอจ้าง (บันทึกข้อความ) — มีลายน้ำ "ร่าง" จนกว่า ผอ. อนุมัติ
- `committee` คำสั่งแต่งตั้งผู้ตรวจรับ/คณะกรรมการตรวจรับพัสดุ — หลังอนุมัติ
- `order` ใบสั่งซื้อ/ใบสั่งจ้าง — หลังออกใบสั่ง (ช่องลงนามผู้สั่งและผู้รับใบสั่งเว้นไว้ลงนามจริง)
- `inspection` ใบตรวจรับพัสดุ — หลังตรวจรับครบ

จำนวนเงินมีตัวอักษรไทย (`src/lib/thai-baht.js`) เลขที่รายงาน/คำสั่ง/e-GP บันทึกได้ทุกเมื่อก่อนปิดงาน

## บทบาท

กำหนดที่ ฝ่ายงบประมาณ › ตั้งค่าผู้อนุมัติ

- `procurement_officer` เจ้าหน้าที่พัสดุ (ผู้บริหารและผู้ดูแลระบบทำแทนได้)
- `procurement_head` หัวหน้าเจ้าหน้าที่พัสดุ (ไม่บังคับ)
- ผู้อำนวยการ ใช้ค่าเดียวกับการอนุมัติเบิกจ่าย (`director_approval`)

ผู้เห็นรายการ: เจ้าหน้าที่พัสดุ การเงิน ผู้อำนวยการ ผู้บริหาร ผู้ตรวจรับของงานนั้น และเจ้าของโครงการ
แจ้งเตือนเข้ากระดิ่งแจ้งเตือนรวม (`procurement:<id>`)
