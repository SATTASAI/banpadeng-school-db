# แก้ไขยอดใช้ไปแล้วจากข้อมูลครั้งแรก

ช่องยอดใช้ไปแล้วรวมอยู่ในการ์ดโครงการทุกฝ่าย รวมถึงโครงการภายในฝ่ายงบประมาณ
แสดงแยกยอดยกมาและยอดเบิกจ่ายที่ยืนยันในระบบ

- `superadmin` และ `executive` แก้ไขยอดรวมได้โดยระบุเหตุผล
- บทบาทอื่นอ่านยอดได้และส่งคำขอพร้อมยอดที่เสนอ/เหตุผลได้
  การส่งคำขอไม่เปลี่ยนยอดและไม่ให้สิทธิ์แก้ไขยอดโดยตรง
- แจ้งเตือนผู้ดูแลระบบและผู้บริหารที่ใช้งานอยู่ทุกคน
  พิจารณาได้ที่ dashboard หรือหน้าโครงการในฝ่ายงบประมาณ/ฝ่ายงาน
- การอนุมัติปรับเฉพาะยอดที่เสนอในคำขอนั้น ไม่เปิดสิทธิ์แก้ตัวเลขอื่น
  ผู้ขอได้รับแจ้งผลในรายการคำขอของตน
- การไม่อนุมัติต้องระบุเหตุผล
- หากยอดเปลี่ยนระหว่างรออนุมัติ ระบบปฏิเสธการอนุมัติด้วยข้อมูลเดิม
  ผู้พิจารณาปฏิเสธคำขอเก่าและให้ผู้ขอส่งยอดที่ตรวจใหม่

ยอดยกมาใหม่ = ยอดรวมที่เสนอ − ยอดเบิกจ่ายที่ยืนยันในระบบ
จึงกรอกต่ำกว่ายอดเบิกจ่ายจริงไม่ได้ และไม่แก้จำนวนเงินหรือเอกสารของรายการเบิกจ่ายจริง
ใช้ทะเบียน `project_expenses` หมวด `opening_balance` สำหรับยอดยกมา
เก็บ id เดิมเพื่อรักษาไฟล์แนบ หากยอดยกมาเป็นศูนย์จะเปลี่ยนสถานะเป็น cancelled
โดยไม่ลบข้อมูลเก่า เมื่อตั้งยอดใหม่กลับมาใช้ id เดิม

บันทึกประวัติทุกการปรับใน project_balance_changes และ audit_logs
ตรวจยอดเดิมและสถานะคำขอภายใน D1 batch เดียวกันกับการเปลี่ยน ledger
เพื่อป้องกันการอนุมัติซ้ำ/พร้อมกันและการเขียนทับยอดล่าสุด
ยอดใช้และยอดเหลือคำนวณจากทะเบียนร่วม จึงปรับตรงกันทั้งฝ่ายงาน งบประมาณ และ dashboard

API:
- PATCH /api/projects/:id/spent-balance: ผู้ดูแล/ผู้บริหารปรับยอด
- POST /api/projects/:id/balance-requests: ส่งคำขอ
- GET /api/project-balance-requests: ผู้พิจารณาดูทั้งหมด คนอื่นเห็นคำขอตนเอง
- POST /api/project-balance-requests/:id/review: อนุมัติ/ไม่อนุมัติ
- POST /api/project-balance-requests/read: รับทราบแจ้งเตือนของตน
