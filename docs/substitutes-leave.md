# จัดสอนแทนจากระบบการลา

เมนูระบบสนับสนุน → จัดสอนแทน ใช้หน้าเดิม ไม่เพิ่มเมนูซ้ำ แสดงเฉพาะเจ้าหน้าที่ฝ่ายบุคลากรที่ผูกทะเบียนหรือทำเนียบฝ่ายตามสิทธิ์เดิม ผู้ดูแลและผู้บริหารที่ไม่ได้เป็นเจ้าหน้าที่ฝ่ายบุคลากรไม่สามารถจัดแทนได้

เลือกวันที่แล้วระบบโหลดใบลาที่ครอบคลุมวันนั้น ทั้งรอพิจารณาและอนุมัติแล้ว ไม่รวมใบลาที่ไม่อนุมัติหรือยกเลิก แสดงชื่อ ประเภทลา จำนวนวัน ช่วงวันที่ สถานะ และเลขใบลา โดยจับคู่กับทะเบียนบุคลากรผ่าน personnel_accounts เพื่อรองรับบัญชีเดิมที่ถูกรวมแล้ว ไม่เปิดเผยเหตุผลหรือข้อมูลติดต่อส่วนตัวใน API จัดสอนแทน

เลือกใบลาเพื่อดึงคาบจากตารางสอนที่เผยแพร่ของภาคเรียนตามวันที่ เลือกครูที่ว่างและบันทึกทีละคาบ ครูที่มีใบลารอพิจารณาหรืออนุมัติในวันนั้นถูกตัดออกจากตัวเลือก แม้ยังไม่เคยมีรายการสอนแทน ไม่เปลี่ยนสถานะอนุมัติใบลาเมื่อจัดสอนแทน

กรณีครึ่งวัน ผู้จัดเลือกเฉพาะคาบที่ต้องสอนแทน เนื่องจากใบลาเดิมไม่มีข้อมูลช่วงเช้า/บ่าย ระบบกันครูที่ลาครึ่งวันออกจากตัวเลือกครูแทนตลอดวันเพื่อป้องกันการจัดผิดช่วงเวลา

บันทึกเลขใบลาไว้ใน substitute_assignments.leave_request_id พร้อมตรวจว่าเป็นครูเดียวกัน วันที่ตรงกัน และยังรอพิจารณาหรืออนุมัติอยู่ ตรวจใบลาต้นทางและใบลาของครูแทนอีกครั้งในคำสั่ง INSERT เพื่อป้องกันสถานะเปลี่ยนระหว่างบันทึก ตารางคำสั่งแสดงเลขใบลาและสถานะล่าสุด หากภายหลังไม่อนุมัติจะแสดงข้อความให้ตรวจคำสั่ง ไม่ลบคำสั่งที่เคยบันทึกโดยอัตโนมัติ

รายการเดิมที่ไม่ได้ผูกใบลายังคงอยู่ การเพิ่มคอลัมน์เป็น migration แบบเพิ่มข้อมูล ไม่มีการลบตารางเดิม การลบใบลาผ่าน foreign key จะปลดเลขอ้างอิงโดยเก็บคำสั่งเดิม ทั้งนี้เครื่องมือล้างข้อมูลของผู้ดูแลใช้การตรวจและสำรองรายการที่สัมพันธ์กันตามขั้นตอนเดิม

Word/PDF ใช้ตัวสร้างคำสั่งเดิม พร้อมตราครุฑและชื่อผู้อำนวยการจากทะเบียนปัจจุบัน ต้องมีตารางสอนที่เผยแพร่และคาบสอนของครูในวันที่เลือกก่อนจัดแทน
