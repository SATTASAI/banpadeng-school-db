# จัดสอนแทนจากระบบการลา

เมนูฝ่ายบุคคล → จัดสอนแทน (ย้ายจากระบบสนับสนุน) ใช้หน้าเดิม ไม่เพิ่มเมนูซ้ำ แสดงเฉพาะเจ้าหน้าที่ฝ่ายบุคลากรที่ผูกทะเบียนหรือทำเนียบฝ่ายตามสิทธิ์เดิม ผู้ดูแลระบบ (superadmin) จัดสอนแทนได้โดยไม่ต้องอยู่ฝ่ายบุคลากร ผู้บริหารที่ไม่ได้เป็นเจ้าหน้าที่ฝ่ายบุคลากรยังใช้สิทธิ์เดิม

เลือกวันที่แล้วระบบโหลดใบลาที่ครอบคลุมวันนั้น ทั้งรอพิจารณาและอนุมัติแล้ว ไม่รวมใบลาที่ไม่อนุมัติหรือยกเลิก แสดงชื่อ ประเภทลา จำนวนวัน ช่วงวันที่ สถานะ และเลขใบลา โดยจับคู่กับทะเบียนบุคลากรผ่าน personnel_accounts เพื่อรองรับบัญชีเดิมที่ถูกรวมแล้ว ไม่เปิดเผยเหตุผลหรือข้อมูลติดต่อส่วนตัวใน API จัดสอนแทน

เลือกใบลาเพื่อดึงคาบจากตารางสอนที่เผยแพร่ของภาคเรียนตามวันที่ เลือกครูที่ว่างและบันทึกทีละคาบ ครูที่มีใบลารอพิจารณาหรืออนุมัติในวันนั้นถูกตัดออกจากตัวเลือก แม้ยังไม่เคยมีรายการสอนแทน ไม่เปลี่ยนสถานะอนุมัติใบลาเมื่อจัดสอนแทน

กรณีครึ่งวัน ผู้จัดเลือกเฉพาะคาบที่ต้องสอนแทน เนื่องจากใบลาเดิมไม่มีข้อมูลช่วงเช้า/บ่าย ระบบกันครูที่ลาครึ่งวันออกจากตัวเลือกครูแทนตลอดวันเพื่อป้องกันการจัดผิดช่วงเวลา

บันทึกเลขใบลาไว้ใน substitute_assignments.leave_request_id พร้อมตรวจว่าเป็นครูเดียวกัน วันที่ตรงกัน และยังรอพิจารณาหรืออนุมัติอยู่ ตรวจใบลาต้นทางและใบลาของครูแทนอีกครั้งในคำสั่ง INSERT เพื่อป้องกันสถานะเปลี่ยนระหว่างบันทึก ตารางคำสั่งแสดงเลขใบลาและสถานะล่าสุด หากภายหลังไม่อนุมัติจะแสดงข้อความให้ตรวจคำสั่ง ไม่ลบคำสั่งที่เคยบันทึกโดยอัตโนมัติ

รายการเดิมที่ไม่ได้ผูกใบลายังคงอยู่ การเพิ่มคอลัมน์เป็น migration แบบเพิ่มข้อมูล ไม่มีการลบตารางเดิม การลบใบลาผ่าน foreign key จะปลดเลขอ้างอิงโดยเก็บคำสั่งเดิม ทั้งนี้เครื่องมือล้างข้อมูลของผู้ดูแลใช้การตรวจและสำรองรายการที่สัมพันธ์กันตามขั้นตอนเดิม

Word/PDF ใช้ตัวสร้างคำสั่งเดิม พร้อมตราครุฑและชื่อผู้อำนวยการจากทะเบียนปัจจุบัน ต้องมีตารางสอนที่เผยแพร่และคาบสอนของครูในวันที่เลือกก่อนจัดแทน

## ปรับปรุง 31 ต.ค. 2569

- **ไม่มีใบลา**: หน้าจัดสอนแทนมีปุ่ม "ไม่มีใบลา (ไปราชการ / อบรม / อื่น ๆ)" เลือกครูที่มีคาบสอนในวันนั้น (`GET /api/substitutes/teachers?date=`) และต้องระบุเหตุที่ไม่อยู่ (เก็บใน `substitute_absences.reason`) — API ตอบ 400 ถ้าไม่มีทั้งใบลาและเหตุผล ครูที่ถูกบันทึกว่าไม่อยู่จะไม่ถูกเสนอเป็นครูสอนแทนในวันนั้น
- **ยกเลิก / เปลี่ยนครู**: `DELETE /api/substitutes/assignments/:id` และ `PATCH /api/substitutes/assignments/:id {substitute_teacher_id}` (เฉพาะผู้มีสิทธิ์จัดสอนแทน) ครูใหม่ต้องว่างตามเงื่อนไขเดียวกับตอนจัด ทุกครั้งบันทึกประวัติใน `substitute_cancellations` (action = cancelled / replaced) ถ้ายกเลิกจนครูที่ไม่อยู่ไม่เหลือคาบที่จัดแทน ระบบลบรายการไม่อยู่ของวันนั้นด้วย
- **แจ้งเตือน**: ครูสอนแทนได้รับกระดิ่ง + LINE (`substitute:<id>:<ครูแทน>` — เปลี่ยนครูแล้วครูใหม่ได้รับแจ้งใหม่) ครูที่ถูกยกเลิก/เปลี่ยนได้รับ "ยกเลิกสอนแทน" (`substitute-cancel:<id>`) เฉพาะวันนี้เป็นต้นไป ลิงก์ไปหน้า คาบสอนแทนของฉัน
- **คาบสอนแทนของฉัน** (`/my-substitutes.html`, เมนู ระบบสนับสนุน): ครูทุกคนเห็นเฉพาะของตัวเองผ่าน `GET /api/substitutes/mine` — คาบที่ต้องสอนแทน, ที่ถูกยกเลิก/เปลี่ยน, คาบของตนที่มีครูสอนแทน และย้อนหลัง 30 วัน

## ระบบเสนอครูสอนแทนอัตโนมัติ (ช่วงชั้น / กระจายภาระ / ตารางเปลี่ยน)

- **ช่วงชั้น**: อนุบาล / ป.1-3 / ป.4-6 ดูจากตารางสอนที่เผยแพร่ ครูที่สอนหลายช่วงชั้น (ควบช่วงชั้น) จัดได้ทุกช่วงที่สอน ครูที่ไม่มีคาบในตาราง (ผู้บริหาร เจ้าหน้าที่ ครูอนุบาลที่ยังไม่อยู่ในระบบ) ไม่ถูกจัด ใช้ทั้งข้อเสนอและการเลือกเอง และ API ปฏิเสธการจัดข้ามช่วงชั้น
- **ข้อเสนอ** (`proposed_teacher_id` ในแต่ละคาบของ `/api/substitutes/coverage`): ทีละคาบ เลือกครูที่ว่างโดยเรียง (1) จำนวนคาบที่ถูกจัดในวันนั้นรวมข้อเสนอก่อนหน้า (2) จำนวนสอนแทนทั้งภาคเรียน (3) เดือน (4) สัปดาห์ (5) วันที่สอนแทนล่าสุดเก่าสุด — ค่าเฉลี่ยใกล้กันและไม่จัดคนเดิมซ้ำ
- หน้าจัดสอนแทนเลือกครูที่ระบบเสนอไว้ให้ (★) กด "ยอมรับข้อเสนอทั้งหมด" หรือเปลี่ยนครูในรายการแล้วบันทึกทีละคาบ
- **สถิติ**: `/api/personnel/substitute-stats`, สถิติบนแดชบอร์ด และเมนูสถิติการสอนแทน เฉพาะฝ่ายบุคคล ผู้บริหาร และผู้ดูแลระบบ (`can_view_stats` ใน `/api/substitutes/permissions`) ครูทั่วไปเห็นเฉพาะรายการคาบสอนแทนของตนในหน้า "คาบสอนแทนของฉัน" ไม่มีตัวเลขสถิติ
- **ตารางสอนเปลี่ยน**: เมื่อเผยแพร่ตารางใหม่ คาบสอนแทนตั้งแต่วันนี้ที่ยังมีคาบเดิม (ครู/ชั้น/ห้อง/วัน/คาบเดียวกัน) และครูสอนแทนยังว่าง จะย้ายไปผูกกับตารางใหม่อัตโนมัติ ถ้าคาบถูกย้าย/ลบ หรือครูสอนแทนมีคาบสอนเองแล้ว จะยกเลิก บันทึกประวัติ แจ้งครูสอนแทน (กระดิ่ง/LINE) และระบบเสนอครูใหม่ในหน้าจัดสอนแทน (ผลลัพธ์ `substitutes:{remapped,cancelled}` ใน `/api/timetable/publish`)
