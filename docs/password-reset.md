# ลืมรหัสผ่าน

หน้าเข้าสู่ระบบมีลิงก์ `/forgot-password.html` ผู้ใช้กรอกอีเมลเพื่อรับลิงก์
`/reset-password.html#token=...` ที่ใช้ได้ครั้งเดียวภายใน 30 นาที
ระบบเก็บเฉพาะ SHA-256 ของ token และยกเลิก session เดิมหลังเปลี่ยนรหัสผ่าน
บัญชีที่ถูกระงับหรืออีเมลที่ไม่มีในระบบได้รับข้อความตอบกลับแบบเดียวกัน
จำกัดการขออีเมลไม่เกิน 3 ครั้งต่อ 15 นาที และเว้นอย่างน้อย 60 วินาที

## ตั้งค่าที่ Cloudflare Worker banpadeng-school-db

- Secret `RESEND_API_KEY`: API key สำหรับส่งอีเมลจาก Resend
- Variable `PASSWORD_RESET_FROM`: อีเมลผู้ส่งที่ใช้โดเมนซึ่งยืนยันกับ Resend แล้ว
  (รองรับ `RESEND_FROM_EMAIL` หรือ `EMAIL_FROM` หากตั้งไว้แล้ว)
- ตัวอย่างผู้ส่ง `โรงเรียนบ้านป่าเด็ง <noreply@banpadengschool.ac.th>`

ไม่เก็บ API key ใน repository หรือไฟล์ frontend หากยังไม่ได้ตั้งค่าจะแสดงข้อความ
ให้ติดต่อผู้ดูแลระบบ แทนการแจ้งว่าส่งอีเมลสำเร็จ
`GET /api/auth/password-reset-status` คืนเฉพาะ `available` เพื่อตรวจความพร้อม
ไม่คืน credentials หรือข้อมูลผู้ใช้

ทดสอบส่งอีเมลจริงด้วยบัญชีของผู้ดูแล แล้วเปิดลิงก์จากอีเมล ตั้งรหัสผ่านใหม่
ตรวจว่าเข้าสู่ระบบด้วยรหัสผ่านใหม่ได้และใช้ลิงก์ซ้ำไม่ได้
