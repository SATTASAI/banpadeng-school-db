# จัดฐานการเรียนรู้ (ฝ่ายบริหารทั่วไป)

เมนู **ฝ่ายทั่วไป → จัดฐานการเรียนรู้** (`/learning-bases.html`) จัดนักเรียน ป.1–6 เข้าฐานการเรียนรู้รายปีการศึกษา

- รายชื่อนักเรียนดึงจากทะเบียนกลาง (`students` สถานะ `enrolled` ชั้น ป.1–6) ทุกครั้งที่เปิดหน้า
- ข้อมูลเก็บใน D1 ของ system: `learning_bases` (ฐานต่อปี: ชื่อ จำนวนรับ ชั้นที่รับ ลำดับ) และ `learning_base_members` (1 คน 1 ฐานต่อปี + ชั้น/ห้อง ณ ตอนจัด)
- แสดงผลเฉพาะ system — ระบบรายงานผลการเรียน (grades) ไม่อ่านตารางนี้
- ปีแรกใช้ชื่อฐานตั้งต้น 18 ฐานจากไฟล์รายชื่อปี 2569 · ปีใหม่คัดลอกฐานจากปีก่อน · แก้ชื่อ/จำนวนรับ/ชั้นที่รับ/เพิ่ม/ลบได้ที่แท็บ ตั้งค่าฐาน
- แก้ไขได้เฉพาะปีการศึกษาปัจจุบัน ปีก่อนดูอย่างเดียว

## สิทธิ์

- แก้ไข: สมาชิกฝ่ายบริหารทั่วไป (`department_staff` หรือช่องฝ่ายในทะเบียนบุคลากร) และ admin (superadmin/executive)
- ดูอย่างเดียว: ครูและบุคลากรทุกคน ที่หน้า **ระบบสนับสนุน → ฐานการเรียนรู้** (`/learning-base-list.html`: แยกฐาน/แยกห้อง ค้นหาทั้งโรงเรียน) · บัญชีผู้ชมภายนอกเข้าไม่ได้

## พิมพ์ PDF / Excel

ปุ่ม "พิมพ์ PDF / Excel" มีทั้งหน้าจัดฐานและหน้าดูรายชื่อ (`public/js/learning-base-export.js`): รายชื่อแยกฐาน (1 ฐานต่อหน้า/ชีต),
รายชื่อแยกห้อง (นักเรียนแต่ละห้องอยู่ฐานไหน), สรุปจำนวน (แต่ละฐานแยก ป.1–6 และเพศ) — PDF ใช้ pdfmake + ฟอนต์ TH SarabunPSK ในรีโป

## วิธีจัดอัตโนมัติ (`src/lib/learning-base-assign.js`)

| วิธี | ความหมาย |
| --- | --- |
| `balanced` | คละชั้น ห้อง และเพศ ให้ทุกฐานเท่ากัน |
| `random` | สุ่มเท่ากันทุกฐาน ไม่สนชั้น/ห้อง |
| `by_grade` | ชั้นเดียวกันอยู่ฐานเดียวกันมากที่สุด |
| `whole_room` | ทั้งห้องเข้าฐานเดียวกัน ห้องที่ใหญ่เกินที่รับ หรือคนที่เคยอยู่ฐานนั้น แบ่งไปฐานถัดไป |

- **ห้ามซ้ำฐานเดิมจนจบ ป.6:** นักเรียนจะไม่ถูกจัดเข้าฐานที่เคยอยู่ในปีการศึกษาก่อน ๆ — นับเป็นฐานเดียวกันเมื่อเป็นฐานต้นทางเดียวกัน (`learning_bases.lineage_id`, คัดลอกข้ามปีแม้เปลี่ยนชื่อ) หรือชื่อเดียวกัน · จัดเองรายคนก็ห้ามเด็ดขาด (API ตอบ 400, หน้าเว็บซ่อนฐานที่เคยอยู่และแสดง "เคยอยู่: …") · คนที่ไม่มีฐานที่ยังไม่เคยอยู่/ว่าง จะเหลือเป็น "ยังไม่มีฐาน"
- ทุกวิธีเคารพจำนวนรับและชั้นที่ฐานรับ แล้วซ่อมคนที่ยังไม่มีที่ด้วยการย้ายคนในฐานที่เต็มไปฐานอื่นที่ว่าง
- ขอบเขต: จัดใหม่ทั้งหมด หรือจัดเฉพาะคนที่ยังไม่มีฐาน · "คงคนที่จัดเองไว้" = ไม่ทับรายการที่เปลี่ยนรายคน (`locked=1`)
- ดูตัวอย่างก่อนบันทึก ผลสุ่มผูกกับ `seed` จึงบันทึกได้ตรงกับตัวอย่าง

## นำเข้าจาก Excel (ศูนย์นำเข้าข้อมูล → ฐานการเรียนรู้นักเรียน)

- คอลัมน์: ชั้น, ห้อง, คำนำหน้าชื่อ, ชื่อ, นามสกุล, ฐานการเรียนรู้ (+ เลขประจำตัวนักเรียน, ปีการศึกษา ถ้ามี) — ไม่มีปีในไฟล์จะถามตอนนำเข้า
- จับคู่แบบหลายช่อง: เลขประจำตัว, ชื่อ–นามสกุล, เพศ (คำนำหน้า), ชั้นตามปีของไฟล์, ห้อง (ปีปัจจุบัน) — อัตโนมัติเมื่อตรง ≥ 3 ช่อง ไม่มีช่องขัดกัน และเลขประจำตัวหรือชื่อตรง · นอกนั้นแสดงช่องที่ตรง/ไม่ตรงให้ผู้นำเข้าเลือก (ค่าเริ่มต้น = ไม่บันทึก) · ไม่พบ = ข้าม (แจ้งรายชื่อ)
- ปีต่อไปรายชื่อมาจาก DMC (นำเข้าที่ระบบเกรด หลัง 10 มิ.ย. / 10 พ.ย.) ประวัติฐานผูกกับนักเรียนคนเดิมอัตโนมัติ — ระบบเกรดจับคู่หลายช่องเช่นกัน ข้อมูลไม่ตรงแจ้งผู้ดูแลระบบ
- บันทึกเป็นข้อมูลของปีนั้น (`method='import'`, ล็อกไว้) ชั้น/ห้องตามไฟล์ · ฐานที่ยังไม่มีในปีนั้นสร้างให้อัตโนมัติ · ใช้เป็นประวัติกติกาห้ามซ้ำฐาน
- นำเข้าได้เฉพาะปีปัจจุบันหรือปีก่อนหน้า

## API

- `GET /api/learning-bases?academic_year=2569`
- `PUT /api/learning-bases/bases` `{academic_year, bases:[{id?, name, capacity, grades}]}` — ฐานที่ไม่อยู่ในรายการ = ปิด (นักเรียนในฐานนั้นกลับเป็นยังไม่มีฐาน)
- `POST /api/learning-bases/auto` `{academic_year, method, scope, keep_locked, seed, apply}`
- `POST /api/learning-bases/import` `{academic_year, mode:'match'|'save', rows}`
- `PUT /api/learning-bases/members` `{academic_year, student_id, base_id|null, force}` — ฐานเต็มตอบ 409 เว้นแต่ `force`
