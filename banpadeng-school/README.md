# ระบบจัดการงานและข้อมูลโรงเรียนบ้านป่าเด็ง — Foundation (ล็อกอิน/สิทธิ์)

ชุดนี้คือ **เฟสที่ 1 (ระบบพื้นฐาน)**: สมัครสมาชิก, ล็อกอิน, และหน้าจัดการสิทธิ์ผู้ใช้งาน
สร้างด้วย Cloudflare Pages + Pages Functions + D1 (ฐานข้อมูล SQL)

## โครงสร้างไฟล์
```
public/            → หน้าเว็บ (HTML/CSS/JS) ที่ผู้ใช้เห็น
functions/api/     → โค้ดฝั่งเซิร์ฟเวอร์ (สมัคร/ล็อกอิน/จัดการผู้ใช้)
schema.sql         → คำสั่งสร้างตารางฐานข้อมูล
wrangler.toml      → ไฟล์ตั้งค่าโปรเจกต์
```

## วิธี Deploy (ใช้ Cloudflare Dashboard อย่างเดียว ไม่ต้องลงโปรแกรมเพิ่ม)

### ขั้นตอนที่ 1: สร้างฐานข้อมูล D1
1. เข้า Cloudflare Dashboard → เมนู **Workers & Pages** → แท็บ **D1**
2. กด **Create database** ตั้งชื่อ `banpadeng_school_db`
3. เมื่อสร้างเสร็จ เปิดฐานข้อมูลนี้ → แท็บ **Console**
4. คัดลอกเนื้อหาทั้งหมดในไฟล์ `schema.sql` ไปวางแล้วกด **Execute** (จะได้ตาราง `users`)
5. หน้ารายละเอียดฐานข้อมูลจะมี **Database ID** — คัดลอกเก็บไว้ (ใช้ในขั้นตอนถัดไป)

### ขั้นตอนที่ 2: สร้างโปรเจกต์ Pages
1. ไปที่ **Workers & Pages** → **Create application** → แท็บ **Pages** → **Upload assets** (หรือเชื่อมกับ Git repo ถ้ามี)
2. ตั้งชื่อโปรเจกต์ เช่น `banpadeng-school`
3. อัปโหลดทั้งโฟลเดอร์นี้ (หรือ push ขึ้น Git แล้วเชื่อม repo) — Build command ไม่ต้องใส่ (เว้นว่าง), Output directory ใส่ `public`

### ขั้นตอนที่ 3: ผูกฐานข้อมูล D1 เข้ากับโปรเจกต์
1. ในโปรเจกต์ Pages ที่สร้าง → ไปที่ **Settings → Functions → D1 database bindings**
2. กด **Add binding**: Variable name = `DB`, D1 database = เลือก `banpadeng_school_db` ที่สร้างไว้
3. บันทึก

### ขั้นตอนที่ 4: ตั้งค่า JWT_SECRET (กุญแจลับสำหรับเซ็นชื่อ session)
1. ไปที่ **Settings → Environment variables**
2. เพิ่มตัวแปรชื่อ `JWT_SECRET` ประเภท **Secret** ค่าเป็นข้อความสุ่มยาวๆ (เช่น ก็อปมาจาก https://1password.com/password-generator/ ยาวอย่างน้อย 32 ตัวอักษร) — **เก็บเป็นความลับ ห้ามให้ใครเห็น**
3. บันทึก แล้วกด **Redeploy** อีกครั้งให้ค่านี้มีผล

### ขั้นตอนที่ 5: ทดสอบใช้งาน
1. เปิดโดเมนของโปรเจกต์ (เช่น `banpadeng-school.pages.dev`)
2. จะเจอหน้า **สมัครสมาชิก** → สมัครบัญชีแรกของคุณ (บัญชีที่สมัครเป็นคนแรกจะได้สิทธิ์ **ผู้ดูแลระบบ (superadmin)** โดยอัตโนมัติ และเข้าใช้งานได้ทันที)
3. คนถัดไปที่สมัคร จะเข้าระบบได้แต่ต้องรอที่หน้า "รอกำหนดสิทธิ์" จนกว่าผู้ดูแลระบบ (คุณ) จะเข้าไปที่หน้า **จัดการผู้ใช้งาน** แล้วกำหนดบทบาทให้ (ครู / ผู้บริหาร / เจ้าหน้าที่ธุรการ / ผู้ดูแลระบบ)

## บทบาท (Role) ในระบบ
- `teacher` — ครู
- `executive` — ผู้บริหาร (เข้าหน้าจัดการผู้ใช้งานได้)
- `staff` — เจ้าหน้าที่ธุรการ
- `superadmin` — ผู้ดูแลระบบ (เข้าหน้าจัดการผู้ใช้งานได้ สิทธิ์สูงสุด)

## ขั้นตอนถัดไป (ยังไม่รวมในเฟสนี้)
- โมดูลจัดการงาน (มอบหมาย/ติดตามงาน/ปฏิทิน/แจ้งเตือน)
- โมดูลข้อมูลนักเรียน (ทะเบียน/ผู้ปกครอง/การมาเรียน/สุขภาพ)
- โมดูลข้อมูลครู/บุคลากร
- โมดูลรายงาน/ส่งออก Excel-PDF

แจ้งได้เลยเมื่อพร้อมให้เริ่มต่อโมดูลถัดไปครับ
